# Operador de Escavadeira

Jogo 3D de operador de escavadeira com câmera em 1ª e 3ª pessoa (Three.js), para navegador e celular.

## Rodar localmente
```
npm install
npm run dev
```

## Publicar no Cloudflare
- Automático: conecte este repositório em Cloudflare → Workers & Pages → Create → Import a repository.
  Deploy command: `npx wrangler deploy`
- Manual: `npm install` e depois `npm run deploy`

O jogo inteiro está em `public/index.html`.
